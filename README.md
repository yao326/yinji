# 印迹 Yinji

> 把走过的路，印在地球上。

印迹是一套面向个人照片的 3D 地球相册。它不是集中托管平台，而是让每个人在自己的电脑或 NAS 上运行，照片始终归用户自己所有。

## 当前状态

这是第一阶段的可运行界面原型：

- 3D 地球作为首页
- 地点照片以扑克牌方式堆叠显示
- 每个地点可设置封面照片
- 点击地点展开照片列表
- 点击照片查看大图
- 电脑和手机自适应
- PWA 安装能力
- 可从本机导入照片，照片仅保存在浏览器本地

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。

## 产品边界

第一版坚持这些原则：

- 不提供集中托管
- 不上传用户照片到项目作者服务器
- 不保存用户的密码或照片
- 不要求用户单独安装 Immich
- 不强制购买付费地图
- 不做社交和共享照片

后续会通过 Immich 提供的官方连接能力读取用户自己的照片库。Immich 将作为内部组件，用户只需要登录印迹。

## 技术方向

- React + TypeScript + Vite
- MapLibre GL JS 地球投影
- PWA 网页应用
- Immich 作为隐藏的照片库和用户系统

详细设计见 [产品方案](docs/产品方案.md) 和 [技术架构](docs/技术架构.md)。
