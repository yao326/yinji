# 印迹产品方案

## 一句话定位

印迹是一套开源、可自托管的 3D 地球相册，用照片记录自己走过的世界。

## 核心用户

- 希望在地球上查看自己照片的人
- 重视照片隐私的人
- 有电脑、NAS 或小型服务器的人
- 愿意自行安装开源项目的人

## 核心体验

1. 用户安装一次印迹。
2. 用户注册或登录自己的本地账号。
3. 用户导入照片。
4. 系统读取拍摄时间和位置。
5. 首页显示完整 3D 地球。
6. 同一地点的照片以扑克牌堆叠显示。
7. 用户可以指定该地点的封面照片。
8. 点击地点展开照片，再点击照片查看大图。

## 第一版范围

- 地球首页
- 照片导入
- 位置读取
- 地点堆叠
- 自定义封面
- 照片大图查看
- 电脑和手机自适应
- PWA 桌面图标
- Docker 一键安装

## 第一版不做

- 集中托管用户照片
- 共享相册和社交关系
- 360° 全景
- 连续街景
- AI 面部识别
- 原生安卓和苹果应用
- 强制付费地图

## 后续候选功能

- 旅行路线
- 按国家、城市、年份浏览
- 地图分享链接
- 家庭成员共同使用
- 手机自动备份
- Windows 桌面安装包
