# 印迹技术架构

## 总体结构

```text
用户电脑或 NAS
├── 印迹网页（PWA）
├── Immich（隐藏的照片库、账号和上传能力）
└── 用户自己的原图存储
```

项目作者只发布代码和安装包，不运营集中式照片服务器。

## 前端

- React + TypeScript + Vite
- MapLibre GL JS
- 地球投影作为首页
- 自定义地点标记，不直接使用数字聚合圆点
- PWA 支持电脑桌面和手机主屏幕图标

## 照片后台

计划使用 Immich，原因是它已经具备：

- 多用户和权限隔离
- 手机照片备份
- 原图保存
- EXIF 和位置读取
- 相册和分享能力
- 官方 API

用户不需要直接使用 Immich 界面。印迹只通过 API 读取用户自己的照片。

## 隐私原则

- 默认单实例自托管
- 每位用户的照片留在自己的设备
- 作者服务器不保存原图
- 地图连接凭据由用户自己配置
- 公开部署时不得把不同用户照片混在一起

## 地图

默认使用免费地图服务；用户可以配置自己的 MapTiler、Mapbox 或其他地图服务。地球渲染由 MapLibre 完成，避免被单一地图供应商锁死。

## 原图与预览

- 原图按原始字节保存
- 缩略图和查看图可以单独生成，不覆盖原图
- Photoshop 等修图后的文件需要单独检查位置和设备信息
